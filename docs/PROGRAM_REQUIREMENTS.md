# TOKEN-IGNITION 申请要求快照

核实日期：2026-10-28；公开 program 配置版本：4。

权威来源：[官网](https://token-ignition.joulebeat.com/)、[公开规则配置](https://token-ignition.joulebeat.com/config/program.json)、[表单文案/前端](https://token-ignition.joulebeat.com/assets/app.js)。规则可能变化，实际提交时以网站显示为准。

申请使用 GitHub 登录，账号至少 30 天。当前公开配置为 7 天试跑、28 天完整周期；申请卡时上限分别为 2,000 与 50,000。上限不是保证配额；本 proposal 请求远小于上限的 48/480 A100 卡时。

官网实际七项是：方向、研究问题、基线、指标与防作弊、实验设计、算力、贡献者代表作与私密联系方式。评审核查研究范围、能力证据、可追溯基线、程序化指标、动作空间、评测完整性及算力周期。

本申请选 `eval`。论文参考成绩不能当作本项目实测值，公开 proposal 也不能冒充既有研究履历。

当前配置允许新申请间隔 7 天、原申请最多修改 3 次；网站说明会先给 AI 报告，再由研究组复核。按报告修改后再次提交，仍受当时规则限制。

提交申请走官网表单。官方 [公开账本](https://github.com/Protocol-zero-0/token-ignition-ledger) 用于展示记录，不是要求申请人向其发 PR。申请通过后再按资助流程运行与提交公开成果。

官网要求成果公开，并允许负结果；署名归贡献者。私人联系方式用于联络及算力发放，不能放进本公开仓库。最终联系信息与网站登录需要申请人本人完成。
