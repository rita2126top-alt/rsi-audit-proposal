## 运行与完整性边界

候选程序无权读写主机数据、账本或密钥；可信协调器与主机管理员仍属于信任边界。HMAC 与本地承诺能发现相对于已保存锚点的变化，不能阻止管理员同时替换整套文件。正式运行前应外部保存数据承诺，冻结后在审计前外部保存 `freeze.json`。

可处理的异常会保存阶段墙钟与已知使用量；没有完整 token 回执的操作明确标为未知，物理 token 总额相应是下界。`command.inprogress` 保留 active/completed 状态；completed 必须匹配账本最后一条 HMAC 完成事件和当前状态锚点。active 或证据不匹配的硬中断默认拒绝自动恢复，不能通过删标记把未核算重跑伪装为免费。跨运行的项目总预算与硬任务时限由外部调度记录负责。
